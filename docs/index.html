Everything is Crab Mod Loader

Crabtya

Crabtya is a folder-based mod loader for Everything is Crab. Drop mod folders into game/Mods, launch the game, and run content + DLL mods with isolation so one bad mod does not break everything.

Get Releases Troubleshooting

What It Is

A native-feeling loader UI with a small Crabtya status label, a MODS main-menu button, and a dedicated in-game mod settings page, built on BepInEx IL2CPP.

What It Allows

Use content mods and managed DLL entrypoint mods. Keep mods organized by folder with per-mod manifests and clear load behavior.

Why It Is Safe

Broken manifests and failing mod entrypoints are isolated. Path handling stays inside each mod folder to avoid accidental escape paths.

How It Works

  1. Place mods in game/Mods/<mod-id> with an eicmod.json manifest.
  2. Crabtya scans mod folders, validates manifests, resolves load order, and applies enabled content surfaces.
  3. Declared DLL assemblies and entrypoints load after startup content, with each mod isolated from failures in others.
  4. Mod settings persist under the game Mods data path and survive restart when the setting surface supports it.

Also Available: Crabtya Lite

Curated QoL improvements without any mod management. No game/Mods/ folder, no manifests, no DLL loading — just the trusted built-in settings.

Achievements enabled Uses original save data No mod folder required Steam-friendly

What Lite Includes

  • Mouse-wheel camera zoom
  • Invert Scroll toggle
  • FOV slider
  • No Intro (skips opening cinematic)

What Lite Does Not Include

No game/Mods/ scanning, no eicmod.json manifests, no DLL mod loading, no Crabtya Mods settings menu, and no isolated modded save. It is intentionally narrow — just the trusted QoL improvements.
